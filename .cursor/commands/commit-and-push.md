1. Run `git status` and `git diff` to review changes.
2. Do not commit secrets, build directories (`build/`, `cmake-build-*`), coverage data, `CMakeUserPresets.json`, IDE settings or ad-hoc scratch outputs.
3. Commit with a clear message describing why the change was made, in the repository's style (one sentence in the imperative ending with a period, then a body).
4. Push only if the user explicitly asked to push.
